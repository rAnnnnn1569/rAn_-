# JT/T 1076—2016《道路运输车辆卫星定位系统 车载视频终端技术要求》重点总结

> 整理依据：用户提供的标准 PDF 原版（22 页，文本型可精确抽取），按苏标/部省/1078 同格式归纳。
> 定位：**视频终端"设备层"技术要求**（只规定终端该有什么能力，不规定通信报文）。配套 1078（视频通信协议）、1077（视频平台协议）。
> 状态：**正式标准**（2016-10-21 发布，2017-01-01 实施），现行有效。

---

## 一、文档基本定位

- 标准族：**JT/T 1076（终端）+ 1077（平台）+ 1078（通信协议）** 三件套，统称为道路运输车辆卫星定位系统视频系列标准。
- 本文件管"**终端该长什么样、具备哪些音视频能力**"：一般要求、功能要求、性能要求、安装要求、试验方法。
- 与 794 的关系：**1076 大量直接引用 JT/T 794—2011**（终端基础标准）。视频终端 = 794 终端 + 音视频编解码/存储/摄像机/拾音器能力。性能、环境、EMC、安装基本全部"见 794"。
- 与 1078 的边界：1076 不定义报文/指令；视频"怎么传、命令字是什么"在 1078。两者之间通过"逻辑通道编号"对齐（1076 表 2 定义物理通道，1078 按逻辑通道号传流）。

---

## 二、核心术语（概念性，务必区分）

| 术语 | 含义 |
|------|------|
| **车载视频终端** | 安装在车辆上，采集车辆环境音视频信息 + 具备卫星定位功能的终端 |
| **主存储器** | 存储音视频、定位等**所有数据**的介质及防护装置（可装卸，如硬盘/SD） |
| **灾备存储装置** | **独立于主存储器**，特殊状态下保存重要数据的介质（实时镜像 + 防火防水抗震） |
| **特殊报警** | 紧急报警、碰撞侧翻报警等**影响车辆安全**的特定报警（非普通视频故障） |

> ⚠️ "主存储器"和"灾备存储装置"是两个独立物理部件，是运维排查录像丢失、火灾/落水后取证的**关键实体**，不要混为一谈。

---

## 三、终端组成（4.2）

**主机**（应符合 794 4.1.1，并含）：
- 音视频编解码模块
- 音视频信号输入/输出接口
- 为摄像机、拾音器供电的电源模块
- 可装卸数据存储器接口
- **实时镜像录像用的灾备存储装置接口**
- USB Host 2.0 及以上标准接口
- 宜含：以太网接口、WIFI 模块

**外部设备**（应符合 794 4.1.2，并含）：
- 车载摄像机、拾音器、可装卸主存储器
- 可选：实时镜像灾备存储装置、乘客计数装置、驾驶行为分析装置

## 四、功能要求（第五章，概念为主）

### 4.1 基本要求（5.1）
- 终端功能满足 **JT/T 794—2011 第 5 章，除 5.4.8、5.4.9**（这两节是 794 里被视频终端替换的部分）。
- 通信方式**宜支持 TD-LTE / FDD-LTE**（4G）。
- 定位模块、无线模块性能均引用 794 第 6 章。

### 4.2 录像 / 录音（5.2）—— 重点
- **音视频压缩方式**：
  - 视频：H.264（ISO/IEC 14496-10）、H.265（ISO/IEC 23008-2）、AVS、SVAC（GB/T 25724）**四选一**。
  - 音频：表 1 共 **28 种**编码（G.7xx 系列、AAC、MP3、AMR、PCM 等），产品需明示。
- **通道定义（表 2）**——运维最常查的对位表：

  | 通道号 | 名称 | 监控区域 | | 通道号 | 名称 | 监控区域 |
  |---|---|---|---|---|---|---|
  | 1 | 音视频 | **驾驶员** | | 8 | 视频 | 车辆左侧 |
  | 2 | 音视频 | **车辆正前方** | | 9 | 视频 | 车辆右侧 |
  | 3 | 音视频 | 车前门 | | 10 | 视频 | 车辆正后方 |
  | 4 | 音视频 | 车厢前部 | | 11 | 视频 | 车厢中部 |
  | 5 | 视频 | 车厢后部 | | 12 | 视频 | 车中门 |
  | 6 | 视频 | 车后门 | | 13 | 视频 | 驾驶席车门 |
  | 7 | 视频 | 行李舱 | | 14~32 | 预留 | 预留 |
  | 33 | 音频 | 驾驶员 | | 36/37 | 音频 | 车厢前/后部 |

- **通道数量（表 3）**：危险品/特大型客运 **5 路视频 1 路音频**；中小型客运 4；货运、出租 **2 路视频 1 路音频**。
- **图像质量**：最低 **704×576（D1）**，且其中一路应 ≥ **1280×720（720P）**，水平分辨力 ≥ **400 TVL**。
- **回放质量（5.2.4.2）**：不同分辨率对应 400/500/650/800 TVL（D1 / 960×576 / 720P / 1080P）。
- **录像总资源 ≥ 150h**：通道 2 编码帧率 ≥ 25fps，其余 ≥ 15fps，全部通道同时达标。
- **数据记录**：音视频与定位信息**同步记录**，可叠加车牌/通道/时间/经纬度/速度字幕；导出格式 **AVI 或 MP4**。
- **录像模式**：开机即录，熄火延时停；休眠时不录像，但支持**特殊报警触发 / 定时触发 / 手动触发**三种启动，启动延时 **≤ 60s**。

### 4.3 本地检索 / 回放 / 备份（5.3）
- 按日期时间、通道号、报警类型检索。
- 回放支持播放/暂停/快进/关键帧快退/慢进/帧进。
- 录像、行车信息、日志经 **USB 导出**，配套软件回放且**不可被篡改**。

### 4.4 报警要求（5.4）—— 与主防联动核心
- **视频报警 4 类**：①视频信号丢失 ②存储器故障 ③特殊报警存储超限 ④其他视频设备故障（如云台故障）。
- **报警联动**：报警时对所有通道音视频数据打标记；标记分**特殊报警 / 普通报警**两种；**特殊报警标识从报警发生前至少 1min 起**，到报警结束或设定条件为止。

### 4.5 数据安全（5.5）—— 运维重点
- **自动覆盖**：存满自动覆盖最旧数据；带特殊报警标记的录像，提醒用户处理后（未删）才可被覆盖。
- **主存储器**：支持非拆机手动装卸、专用工具开启；核心为硬盘时，拆下后需防跌落防撞，接口 USB Device 2.0 或 DC005（5V/2A）。
- **灾备实时镜像 ≥ 2h**：防火、防水、抗震；记录质量同 5.2.3/5.2.4（见附录 B 灾害保护指标）。
- **电源异常保护**：主电低于最低工作电压持续 ≤ 500ms 记录不中断；非正常断电时，已存数据 + 当前缓冲数据**不丢失**。

### 4.6 网络功能（5.6）
- 继承 794 所有监控中心相关功能。
- **实时监控**：至少同时上传任意 2 路实时视频；200kbps 下 CIF 分辨率 ≥ 8fps，平均延迟 ≤ 3s。
- **历史录像**：检索 / 回放 / 调取；按时间调取误差 ≤ 10s；支持**断点续传**；调取到中心的文件为 AVI/MP4。
- **远程设置音视频参数**：码率、帧率、分辨率、关键帧间隔、字幕叠加。

### 4.7 图像分析（5.7）—— ADAS/DSM 终端侧基础
- **乘客计数**：区分上/下车；单次准确度 ≥ 95%，10 次以上总人数 ≥ 90%；可按核载人数实现**超员报警**。
- **驾驶行为分析**：视频判断生理疲劳（≥ 90%）、是否按规定车道行驶（≥ 90%）；按参数设异常驾驶行为报警。

### 4.8 其他（5.8~5.11）
- 支持读取并上报设备 SIM 卡 **ICCID**。
- 支持 TCP 链接无数据时自动断开的超时设定。
- **摄像机**：模拟 CVBS 输出 1±0.2 Vp-p、75±7.5Ω；自动增益/白平衡（2800K~9000K）/背光补偿/彩黑转换/电子快门；光学中心水平 ≥ 500TVL、垂直 ≥ 420TVL、信噪比 ≥ 35dB、彩色最低照度 ≤ 1lx（< 10lx）；数字摄像机 ≥ 600TVL 中心、≥ 720P、≥ 25fps。
- **拾音器**：20Hz~20kHz、-30dB 灵敏度、信噪比 > 40dB、最大声压 110dB、600Ω、2.5Vp-p、全向。

## 六、安装要求（第七章）

## 七、试验方法与附录（第八、九章，简述）
- 功能/电气/环境/EMC 试验均对照前述条款验证。
- **附录 A**：模拟摄像机音视频连接器、灾备存储装置连接器接口形态（开孔 12mm、外螺纹、线针式）。
- **附录 B 灾备存储装置灾害保护最低性能（重点）**：
  - 耐高温火焰 **1100℃ / 15min**
  - 耐低温火焰 **260℃ / 120min**
  - 落水浸泡 **水深 10m / 24h**
  - 振动冲击达到 GB/T 19056—2012 5.9，通电 3 次循环
  - 试验后须能从内部存储部件取出录像并正常回放。
- **附录 C**：主存储器为硬盘时，工作状态机械环境（随机振动 X/Y/Z 各 8h；冲击峰值 300m/s²、18ms、各方向 3 次）。

## 八、与你工作的关联 & 易考点

1. **1076 vs 1078 边界**：1076 = 终端"有什么能力"（设备标准）；1078 = 音视频"怎么传"（通信协议）。排查"通道没画面"先查 1076 通道定义（表 2）+ 摄像机指标，再查 1078 链路/时效口令。
2. **通道编号是三标准通用语言**：驾驶员=通道1、正前方=通道2，主动安全/DSM 摄像头一般挂通道1；平台报警字典、视频调取都按此编号对齐。
3. **灾备存储装置**是火灾/落水/事故后取证的法定保存介质，要求实时镜像 + 防火防水抗震 ≥ 2h；主存储器满则自动覆盖（特殊报警录像提醒后才覆盖）。
4. **特殊报警联动**：从报警前 ≥ 1min 就开始打标录像——这是事后追责/保险取证的时间窗依据。
5. **驾驶行为分析 / 乘客计数**是 1076 里明确的 ADAS/DSM 终端侧功能，对接地方主动安全补充规范报警时，终端这侧能力由本标准约束；报警码体系则属 1078/川标/部省规范（0x01xx / 0x02xx / 0xDxxx 区分，见《JT1078视频通讯协议_重点总结》第七节）。
6. **录像总资源 ≥ 150h、D1 起步、一路 720P** 是验收/过检硬指标；过检（备案过检平台）时终端侧按此核对。
