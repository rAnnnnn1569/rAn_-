# 《JT/T 794—XXXX 道路运输车辆卫星定位系统 车载终端技术要求》重点总结

> 文档性质：交通运输部行业标准（JT/T），**征求意见稿（XXXX 版，尚未发布）**，替代 **JT/T 794-2011**。
> 归口：全国道路运输标准化技术委员会（SAC/TC 521）。
> 起草：交通运输部公路科学研究院、福建省交通运输厅、中国交通通信信息中心 等。
> 适用范围：道路运输卫星定位系统中安装在车辆上的**北斗兼容车载终端设备**的一般要求、功能要求、性能要求、安装要求。
> ⚠️ 注意：当前是"征求意见稿"，编号 `794—XXXX`，**不是已强制实施的正式标准**；现行有效版本为 JT/T 794-2011。本总结按征求意见稿内容整理，落地以正式发布版为准。

---

## 一、文档定位与上下游关系（概念）

- **794 = 终端侧技术要求**（装在车上的硬件/功能），是整个"卫星定位系统"三层标准中的**设备层**。
- 配套关系：
  - 平台侧：`JT/T 796` / `GB/T 35658`《平台技术要求》——管服务器平台。
  - 通信协议：`JT/T 808`（终端↔平台）、`JT/T 809`（平台↔平台）——管报文。
  - 视频：`JT/T 1076`、`JT/T 1078`。
  - 行驶记录仪：`GB/T 19056`（794 直接引用，要求终端具备行驶记录功能）。
- 794 只规定**终端"该有什么能力"**，不规定报文格式；所以本标准的概念最终要靠 808/809 落地成具体消息。

### 与 JT/T 794-2011 相比的主要变化（概念性）
- 范围、引用文件调整；连续驾驶时间定义修改，**新增**：行驶开始时间、有效停车休息、单日累计驾驶时间。
- 一般要求新增**铭牌**内容（含 IMEI）。
- 功能要求大改：新增 **5.2.2 北斗定位功能、5.4.10 车辆信号采集、5.15 使用前锁定、5.16 自动关闭通信、5.17 双向语音通话、5.18 ETC**；删除原"电召服务（5.13）"。
- 性能要求调整振动/冲击条款，电磁兼容新增 **6.6.3 耦合电瞬态发射抗扰度**。
- 安装、附录 A（四类车辆功能配置表）同步更新。

## 二、核心概念与术语

| 术语 | 概念含义 |
|---|---|
| 固件 firmware | 运行在终端微处理器中的嵌入式软件 |
| 电子运单 electronic travel permit | 含车辆信息、客货信息等的电子数据 |
| 行驶开始时间 | 车辆从静止转为行驶（速度>0 且持续 ≥10s）的时刻 |
| 有效停车休息 | 车辆转为静止（速度=0）且持续 ≥20min |
| 单次连续驾驶时间 | 同一驾驶人从"行驶开始"到"有效停车休息开始"之间的驾驶时长 |
| 单日累计驾驶时间 | 同一驾驶人 24h 内各次连续驾驶时间之和 |
| 监控中心 monitoring centre | 对车辆道路运输进行监控的软件平台 |
| 休眠 sleep | 车辆熄火后，终端仍保持与监控中心联系的特殊状态 |
| ACC | 汽车点火开关转向锁的专用档位（用于判断点火/熄火） |
| CAN | 控制器局域网络（车辆总线，采油耗/故障等） |

## 三、一般要求（设备本体概念）

- **终端组成**
  - 主机：微处理器 + 数据存储器 + 卫星定位模块 + 车辆状态采集模块 + 无线通信模块 + 实时时钟 + 数据通信接口；可含显示器/打印机/读卡器（不含则列为外部设备，但主机须留接口）。
  - 外部设备：定位天线、通讯天线、应急报警按钮、语音报读装置；可含通话、操作键、读卡器、打印机、显示器、图像/视频/音频、驾驶员身份/电子运单/物流/收费/服务评价等采集设备。
- **外观/铭牌**：铭牌须清晰耐久、醒目位置，含名称型号、厂名商标、出厂年月编号、执行标准代号、**终端 IMEI 号**；文字图形须中文（其他文字在下方/右方）。
- **材质**：无毒害、无放射性。
- **机壳防护**（QC/T 413）：不含显示器/打印机/读卡器 → **IP53**；含其一 → **IP43**。

## 四、功能要求（核心概念，按类别）

### 1. 自检
终端以信号灯/显示屏明示主要状态（定位/通信模块、主电源、天线、外接设备），按预设频率自检（频率可由监控中心设）；故障则显示类型并存储上传。

### 2. 定位（含北斗）
- 提供实时时间/经纬度/速度/高程/方向；盲区（通信中断）以 FIFO 存 **≥10000 条**定位信息，恢复后补报（可压缩）。
- 支持时间/距离/外部事件触发上报；休眠态也按间隔上报；报警/重点车可 **1s** 间隔；支持 **A-GPS** 辅助定位。
- **北斗定位功能（新增）**：采北斗定位结果及详细数据（伪距、DOP、信噪比、有效卫星数）；可响应"添加/删除北斗采集区域"指令；存 **≥24 个矩形区域**，驶入自动采集上传、驶出停止；存 **≥2000 条**详细数据（超容 FIFO 丢弃）；支持北斗双模模块在线/本地升级。
- **定位性能**：行驶态定时报送 ≤5s（最小）~≤30s（最大）；定距 ≤100m~≤500m；实时定位应答 ≤10s；24h 累计时间误差 ≤±5s。

### 3. 通信
- 方式：除 GSM/CDMA 外，至少支持 TD-SCDMA/WCDMA/CDMA2000/TD-LTE/FDD-LTE 之一，或北斗通信；优先分组数据传输，无则短信，再则北斗。
- 要求：支持**主+备两个远程连接**，主中断自动切备；无法注册时 FIFO 暂存；支持批量收发、断点续传。

### 4. 信息采集
驾驶员身份（JT/T 825 IC 卡，换驾自动侦测）、电子运单、车辆 CAN（油耗/故障）、载运状态、出租运营数据（JT/T 905.2）、收费结算（公交一卡通/银行卡）、图像（≥2 路摄头、红外、≥2000 张 FIFO、可标记防覆盖）、音视频（JT/T 1076）、车辆状态（≥5 开关量 + ≥2 模拟量，随定位上传）。

### 5. 行驶记录
须符合 **GB/T 19056** 汽车行驶记录仪要求，提供数据分析软件，支持实时/条件检索上传与接口导出。

### 6. 监听 / 通话
监听：监控中心下发号码，终端拨打进入监听（扬声器关）；首次不通连拨 3 次、间隔 30s；无图音视频功能的终端人工报警时主动拨打预设监听号。通话：电路域通话 + 通话管理（限制/存储/电话簿≥20 人/回拨/音量/自动摘机），可仅呼入/呼出名单由中心设。

### 7. 休眠
ACC 检测熄火 → 发熄火信号并休眠；关非必要设备（定位模块按需唤醒）；上传频率可远程降；**电瓶欠压后转内置备用电池，电量耗尽自动关机；休眠平均功率 ≤1.5W**。

### 8. 警示（重点：人工报警 vs 自动提醒）
- **人工报警**：驾驶员触应急报警按钮（抢劫/事故/故障等），上传报警并关语音报读；有图音视频立即启用；无信号地区经**北斗短消息**报警；须防误操作。
- **自动提醒**（终端按中心设定条件触发，共 14 类）：
  1. 区域提醒（存 ≥24 个多边形/圆形区域，禁入/禁出）
  2. 禁行时段提醒（**默认凌晨 2:00–5:00**）
  3. 路线偏离提醒（存 ≥24 条路线，每条 ≥16 点折线）
  4. 超速提醒（速度阈值触发）
  5. 疲劳驾驶提醒（**单次连续默认 4h、单日累计默认 8h**）
  6. 电瓶欠压提醒（转备用电池）
  7. 断电提醒
  8. 剪线提醒（定位天线被剪）
  9. 超时停车提醒
  10. 终端故障提醒
  11. 轮胎压力异常提醒（与胎压监测通信）
  12. 侧翻提醒（与车身稳定系统通信）
  13. 前撞提醒（与 AEB/前撞预警通信）
  14. 车道偏移提醒（与车道保持辅助通信）
- 触发即向中心上传警示/向手机发短信；可接收指令取消；以语音报读+声光文字提示。

### 9. 终端管理
无线远程：注册/注销、固件更新、参数修改查询、复位/恢复出厂；更新/改参遇掉电须自动恢复；也支持本地（SD/USB）。可 USB+串口设置输出。

### 10–13. 人机交互 / 信息服务 / 多中心接入 / 故障远程诊断
- 人机交互：语音报读+显示+信号灯/蜂鸣器；驾驶员按键/触摸屏/遥控操作；**货运终端显示 ≥5 英寸、支持触摸**。
- 信息服务：主动上报/中心下发，分类管理；政府公告语音+弹窗；存最近 **≥50 条**各类记录可查。
- 多中心接入：同时连 **≥2 个中心**、向多中心上报，但**只执行主中心指令**；支持域名接入；**货运终端主域名 `jt1.gghypt.net`、备 `jt2.gghypt.net`**。
- 故障远程诊断：响应中心指令按指定频率上传 CAN 当前故障码（≥2 路内置 CAN），中心下发故障指示屏显。

### 14–18. 使用前锁定 / 自动关闭通信 / 双向语音 / ETC / 四类车辆
- 使用前锁定（**货运终端必备**）：未录终端 ID/SIM 等基本信息时锁定，初次使用须录入并向中心注册方可启用。
- 自动关闭通信（可选）：危险区域（加油站/油库等）自动关通信；存 **≥127 个危险区域**，驶入关闭、驶出重启并补传。
- 双向语音通话（可选）：一键呼叫中心。
- ETC（可选）：与车辆不停车收费系统通信并上传信息。
- **5.19 四类终端**：危险品运输车、货运、客运、出租汽车，功能配置见附录 A。

## 五、性能要求（关键指标概念）

- **整体**：24h 持续稳定工作；**MTBF** 最低 3000h（出租 5000h、危险品 8000h）；可扩展性（USB/总线/制动速度信号接口，可 RS232/485）。
- **卫星定位模块**：接收通道 ≥12；灵敏度优于 **-130dBm**；水平精度 ≤15m、高程 ≤30m、速度 ≤2m/s；差分（可选）1–5m；最小位置更新率 1Hz；热启动捕获 ≤10s。
- **无线通讯模块**：协议支持同 3.3.1；误码率/发射功率符合 YD/T 系列；北斗通信符合 JT/T 766-2009。
- **电气适应**：
  - 主电源为车载电源；内置备用可充电电池，**失主电后工作 ≥1h**（够报警/传必要数据）。
  - 电压波动：12V 系统 9–16V、24V 系统 18–32V；极性反接耐受 1min（仅熔断器可坏）；过电压 12V→24V、24V→36V 耐受 1min。
  - **断电保护**：断电前信息至少保持 **15 天**。
  - 低压保护门限：12V→8.5±0.5V、24V→17.0±1.0V、36V→26.0±1.0V；恢复超上限切回车载电瓶。
- **环境适应**：存储温度 **-40~85℃**、工作温度 **-20~70℃**；振动/冲击符合 GB/T 28046.3。
- **电磁兼容（EMC）**：
  - 静电放电（GB/T 19951）不低于 **Ⅲ级**（接触 ±6kV / 空气 ±8kV，B 类评定）。
  - 沿电源线电瞬态传导抗扰（GB/T 21437.2）Ⅲ级 1.2a/3a/3b。
  - 耦合电瞬态发射抗扰（GB/T 21437.3，新增）Ⅲ级，A 级。

## 六、安装要求（概念）

- 总体：不改车辆原电气结构/布线，不产生安全隐患。
- 主机：远离碰撞/过热/直射/废气/水油尘，避安全气囊/ABS/敏感电子；**螺丝固定、禁胶粘**；两侧留接插空间；线隐蔽无外露。
- 天线：远离敏感电子设备，保信号。
- 布线：取电在 **ACC 之前**；车速信号取车速传感器脉冲、制动取制动开关量；线夹固定走波纹管；不借车保险丝，电源线额定电流远大于终端工作电流。
- 外部设备：应急报警按钮方便且防误触。
- 完成：专人检查后方可通电初始化；按说明书远程测试各项功能。

## 八、重点 / 易考点（概念速记）

1. **版本状态**：794—XXXX 是征求意见稿，替代 794-2011，现行有效为 2011 版。
2. **北斗兼容**：本标准终端须北斗兼容；新增北斗定位功能（区域采集、详细数据、双模升级）。
3. **盲区补报 ≥10000 条**；休眠功率 **≤1.5W**；备用电池 **≥1h**；断电保护 **≥15 天**。
4. **疲劳阈值**：单次连续 **4h**、单日累计 **8h**（默认可远程设）；禁行时段 **2:00–5:00**。
5. **定位性能**：定时 5–30s、定距 100–500m、实时应答 ≤10s、24h 误差 ≤±5s。
6. **定位精度**：水平 ≤15m、高程 ≤30m、速度 ≤2m/s；灵敏度优于 -130dBm。
7. **机壳防护**：无屏/打/读卡器 IP53，有其一 IP43。
8. **MTBF 分级**：普通 3000h、出租 5000h、危险品 8000h。
9. **多中心**：连 ≥2 中心、只听主中心指令；货运域名 jt1/jt2.gghypt.net。
10. **警示 14 类自动提醒** + 人工报警（含北斗短消息报警、防误触）。
11. **四类终端**功能差异（○△×），货运"使用前锁定"为硬要求。
12. 与平台(796/35658)、协议(808/809)、记录仪(19056)、视频(1076/1078) 的配套关系——794 只定终端能力，报文在 808/809 落地。
