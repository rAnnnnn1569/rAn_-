# 常用命令速查

日常运维里真正会用到的那几条命令，按「看得见什么」分类，不按命令名字分类。

> 说明：文中服务器 IP 已替换为文档保留段（`192.0.2.0/24`），路径与主机名保留原样。

---

## Linux

### 网络

**抓包定位 NAT 转发是否成功**

```bash
tshark -i any -Y "ip.dst == 192.0.2.148 && tcp.dstport == 8055" -c 10 -T fields -e data
```

**抓指定主机与端口的交互**

```bash
tshark -i any -f "host 192.0.2.143 and port 7865" -c 10 -T fields -e data
```

括号里的 `-T fields -e data` 是把抓到的包直接输出成十六进制，方便丢给解析器。

**通用抓包骨架**

```bash
sudo tcpdump -nn -s0 -X -c 20 -i 网卡名 host 地址
```

`-T fields -e data` 和 `-X` 都是为了看原始报文；不看原始报文就不用加。

**808 / 809 原始报文在哪看**

- **808**：日志里就能看。`/cet/src/proxyServer/log/` 这个目录映射的就是 proxyServer 容器的日志。注意要在 Xftp 里看，否则中文乱码。
- **809** 有两种情况：
  1. 经过 27 服务器转发的 —— 用 tshark 抓包。历史报文有没有落日志，不确定。
  2. 星冠和上级直连的 —— 直接看星冠服务器的日志，里面有原始报文。

**端口通不通**

```bash
telnet ip 端口
```

**保存防火墙规则**

```bash
service iptables save
```

#### 用 curl 判断一个域名到底通不通、跳没跳走

```bash
# 1. 拿状态码 + 耗时 + 最终落地 URL（判"有没有跳转到娱乐站"）
curl -sS -o /dev/null \
  -w "code=%{http_code} tls=%{time_appconnect}s total=%{time_total}s final=%{url_effective}\n" \
  -L --max-time 10 https://域名

# 2. 直连内网端口测 TCP 通不通（绕过代理，rc=28 ≠ 端口不通）
curl --noproxy '*' -m 5 http://1.2.3.4:8080        # 非 000 = 通；000 = 不通

# 3. 查证书链 + 响应头（证书过期 / 中间人必看）
curl -vkI https://域名

# 4. 看页面有没有禁止内容
curl -sSL -m 8 https://域名 | grep -iE "抖音|娱乐|直播"

# 5. 下载文件
curl -sSL -o out.bin https://url
```

第 2 条那个坑值得记一下：**`--noproxy '*'` 不加的话，请求会走代理，出来的 `rc=28`（超时）不代表端口不通。**

### 正则

```bash
grep -vE '^\s*(#|$)' 文件路径      # 去注释 + 去空行
```

### 文件

```bash
locate -i -n 10 -e 文件名
```

- `-n` 限制返回条数
- `-e` 只显示真实存在于磁盘上的文件
- `-i` 不区分大小写

注意：刚删除和刚创建的文件查不到。不确定文件是否刚变动，先 `updatedb` 更新索引。

### 后台运行与输出重定向

```bash
nohup python3.8 -u lifecycle_portal.py >> nohup.out 2>&1 &
```

`-u` 关掉 Python 的输出缓冲，`>>` 是追加而不是覆盖。

**为什么非得写 `2>&1`**

每个进程默认有三个 fd：

| fd | 名称 | 默认指向 |
|---|---|---|
| 0 | stdin | 键盘 / 终端 |
| 1 | stdout | 终端屏幕 |
| 2 | stderr | 终端屏幕 |

终端上刷的东西**全部来自 fd1 和 fd2**。要让屏幕安静，得把这两条都改向：

- `>> nohup.out` —— 把 fd1 从「终端」改到「文件」。**核心，没有它一切白搭**
- `2>&1` —— 把 fd2 改成「和 fd1 一样」。**补漏，让 stderr 也跟着走**

## Windows

### 网络

```cmd
netstat -ano | findstr "端口"          :: 查看某个端口的状态
netstat -ano | findstr ESTABLISHED     :: 查看实时 TCP 连接
```

```cmd
netsh advfirewall firewall add rule name="zwbd-12091-12092-12056" dir=in action=allow protocol=TCP localport=12091,12092,12056
```

最后一条是加防火墙放行端口，`name` 里带上端口号，后面排查时一眼能认出这条规则是干什么的。
